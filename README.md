# NOVA AI - Productivity Platform

## 🚀 Project Description

NOVA AI is a modern and responsive AI-powered productivity platform designed to help teams manage projects, automate repetitive tasks, and collaborate efficiently.

The project is built as a multi-page web application with a modern SaaS-style user interface. It focuse on responsive design, reusable React components, smooth navigation, interactive UI elements, and a professional user experience.

**Tagline: Build Better. Work Smarter.**

## 💻 Installation Instructions

### 1. Clone the repository

```bash
git clone https://github.com/anish1840/NOVA-AI-Productivity-Platform..git
```

### 2. Navigate to the project folder

```bash
cd nova-ai-productivity-platform
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Open the URL shown in your terminal.

Usually:

```text
http://localhost:5173
```

---

## 🎨 Design Decisions

The design follows a modern SaaS and AI product style.

### Design choices include:

* Dark modern interface
* Blue and violet gradients
* Glassmorphism-inspired cards
* Clean typography
* Rounded UI elements
* Minimal and professional layout
* Responsive grid systems
* Consistent spacing
* Interactive hover effects

The goal was to create a modern and professional productivity platform that looks similar to real-world SaaS products.
